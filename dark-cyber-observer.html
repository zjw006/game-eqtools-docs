SEC.01

游戏概述 GAME OVERVIEW

Observer 是一款第一人称赛博朋克恐怖侦探游戏，核心玩法围绕环境探索、线索搜集、神经入侵审讯展开。与传统 RPG 不同，它没有商店、天赋树、成就或图鉴系统——UI 设计完全服务于叙事沉浸与恐怖氛围。

核心玩法 GAMEPLAY

环境探索——第一人称步行模拟，在衰败的克拉科夫贫民窟大楼中调查
线索搜集——通过电磁/生物/夜视三种增强视觉扫描环境中的可互动物品
神经入侵——侵入死者或嫌犯的大脑，在其混乱的记忆碎片中寻找真相
审讯对话——与 NPC 进行分支对话，选择影响剧情走向
关键机制：游戏没有传统战斗系统，"战斗"体现为神经入侵中的精神对抗——在他人意识世界中躲避恐怖幻象、解开谜题。

世界观设定 SETTING

2084 年——反乌托邦未来，波兰克拉科夫贫民窟
纳米瘟疫——Nanophage 数字瘟疫杀死了大量身体/意识改造者
大崩溃——战争与瘟疫后的文明崩塌，人命微贱
企业统治——Chiron 公司垄断一切，AR 广告无处不在
观察者——财团资助的精英调查员，可合法侵入他人思维
氛围基调：压抑、衰败、霓虹与腐肉交织的暗黑赛博朋克——Blade Runner meets 精神恐怖。
SEC.02

设计哲学 DESIGN PHILOSOPHY

Observer 的 UI 设计遵循"消失即存在"的悖论——通过最大限度减少界面元素的存在感，反而强化了玩家对游戏世界的沉浸。这是 diegetic UI 设计的极致实践。

01

零常驻 HUD

画面四周没有任何常驻 UI 元素——没有血条、没有小地图、没有任务追踪。所有信息仅在需要时通过 AR overlay 短暂浮现，最大限度保持视野纯净。

02

AR 全息叠加

所有界面信息都以世界内 AR 投影呈现——案件日志、互动物品高亮、NPC 信息标签直接投射在环境中，仿佛角色通过神经植入体"看到"的数据层。

03

三重视觉模式

电磁视觉（蓝）扫描电子设备，生物视觉（红）检测有机生命，夜视（紫）在黑暗中视物。三种模式不仅改变画面滤镜，更重构了玩家与世界的交互方式。

04

拖拽式互动

与物品互动需鼠标拖拽开门、移动物体，而非简单的按键交互。这种"费力感"强化了第一人称的物理存在感，参考 Alien: Isolation 的机械互动。

05

神经入侵界面

侵入他人大脑时，UI 彻底崩解——画面扭曲、色彩偏移、现实与幻觉边界消融。此时的"界面"就是疯狂本身，形式与内容达成完美统一。

06

霓虹即信息

环境中的霓虹灯、全息广告、AR 标识不仅是装饰，更是世界观叙事的载体。Chiron 公司的产品广告、反乌托邦标语无处不在，UI 与环境设计无缝融合。

SEC.03

界面模块分析 INTERFACE ANALYSIS

由于 Observer 是线性叙事恐怖冒险而非 RPG，它没有传统意义上的商店、天赋、成就或图鉴系统。以下分析聚焦于游戏实际拥有的核心界面模块，并与 Fire Roach Killer 的设计需求进行对照。

① 主界面 MAIN MENU

布局方案 LAYOUT

极简的终端式标题画面——纯黑背景上仅有四个选项：新游戏 / 设定 / 可收集物品 / 退出。没有华丽的背景动画，没有角色展示，只有冰冷的等宽字体与细微的 CRT 扫描线效果。

[新游戏]NEW GAME
[设定]SETTINGS
[可收集物品]COLLECTIBLES
[退出]EXIT

设计要点 KEY FEATURES

1. 纯黑背景——没有任何场景或角色，只有绝对的黑暗，暗示 2084 年的绝望
2. 等宽终端字体——仿 DOS 终端的 monospace 字体，强化冰冷机械感
3. 选项极简——仅 4 项，没有难度选择、没有存档管理，一切从简
4. 选中态——文字轻微发光（霓虹蓝），无多余装饰
5. 可收集物品入口——单独列出，暗示探索价值与世界观深度
对 Fire Roach Killer 的启示：主界面可以考虑加入PDA 终端式极简列表，用等宽字体 + 霓虹发光选中态替代华丽按钮。

② 战斗 HUD / 探索界面 EXPLORATION HUD

布局方案 LAYOUT

Observer 的 HUD 是游戏史上最极简的设计之一——画面四周完全没有任何常驻元素。玩家通过第一人称视角直接观察世界，只有在交互或扫描时，AR overlay 才会短暂浮现。

画面中央纯游戏视野 · 零遮挡
交互时AR 标签短暂浮现于目标物上
扫描时视觉模式滤镜 + 可互动物品高亮
受伤时屏幕边缘红色脉冲呼吸

设计要点 KEY FEATURES

1. 零常驻 HUD——没有血条、没有弹药、没有小地图，彻底解放视野
2. AR 交互标签——看向可互动对象时，文字标签直接浮现在物体表面（如"开门""拾取"）
3. 拖拽交互——鼠标拖拽开门/移动物体，而非按键，增加物理存在感
4. 视觉模式提示——当前激活的视觉模式通过画面整体色调暗示（蓝/红/紫）
5. 受伤反馈——无血条，仅通过屏幕边缘红色呼吸渐变 + 心跳音效传达伤害
6. 案件日志——按滚轮呼出 AR 控制面板，查看案件档案与目标
对 Fire Roach Killer 的启示：战斗 HUD 可考虑进一步减少常驻元素，将 HP/燃料信息改为屏幕边缘的微妙渐变或仅在受击时显示。

③ 案件日志 / 数据面板 CASE LOG / DATA PANEL

布局方案 LAYOUT

按鼠标滚轮呼出 AR 控制面板——这是游戏中唯一的"菜单"界面。面板以全息投影形式浮现在画面中央，不暂停游戏，背景仍可见。包含案件档案、目标列表、健康状态。

案件档案 CASE FILES已收集线索与证据
目标列表 OBJECTIVES当前任务目标
健康状态 HEALTH植入体负荷 / 精神状态

设计要点 KEY FEATURES

1. 不暂停的 AR 面板——呼出时游戏不暂停，背景仍可见，保持紧张感
2. 全息投影质感——面板边缘有扫描线闪烁与轻微色差，模拟廉价 AR 设备
3. 等宽字体档案——所有文本使用 monospace 字体，像警局数据库的终端输出
4. 线索关联——档案中的线索可互相链接，帮助玩家推理案情
5. 精神负荷指示——健康状态不仅显示肉体伤害，更显示神经入侵对精神的侵蚀
对 Fire Roach Killer 的启示：图鉴/成就系统可采用类似的AR 全息面板设计，不暂停游戏，叠加在画面上。

④ 神经入侵 / 审讯界面 NEURAL INTERROGATION

布局方案 LAYOUT

Observer 最核心的 UI 创新——当 Daniel 使用"食梦者"设备侵入他人大脑时，传统 UI 彻底消失。玩家进入被入侵者的精神世界，这里的一切都是扭曲的、非欧几里得的、充满象征意义的。

现实崩解走廊扭曲 · 墙壁融化 · 重力失效
色彩暴力高饱和色块冲击 · 色差偏移 · 噪点
象征物记忆碎片化为可互动实体
声音设计低语 · 尖叫 · 心跳 · 电子噪音

设计要点 KEY FEATURES

1. UI 即疯狂——没有传统界面，整个精神世界就是 UI，玩家在混乱中自行寻找线索
2. 环境叙事——记忆以象征性场景呈现（童年房间扭曲成迷宫、创伤化为怪物）
3. 色彩心理学——不同情绪用不同主色调：愤怒=血红、悲伤=靛蓝、恐惧=惨白
4. 时序错乱——过去、现在、幻想在空间中同时存在，打破线性时间感
5. 交互隐喻——解开记忆谜题需理解被入侵者的心理创伤，而非逻辑推理
6. 退出机制——精神负荷过高时被迫退出，屏幕剧烈闪烁后回归现实
对 Fire Roach Killer 的启示：加载界面或特殊关卡可借鉴这种"UI 崩解"美学——故障艺术 + 色彩暴力 + 非欧几何空间。

⑤ 增强视觉模式系统 VISION MODES

三种视觉模式 VISION MODES

Observer 最具辨识度的 UI/UX 设计——玩家可随时切换三种增强视觉模式，每种模式彻底改变画面外观并高亮不同类型的可互动物品。这是游戏最核心的"能力系统"。

电磁视觉 ELECTROMAGNETIC (E) 生物视觉 BIOLOGICAL (Q) 夜视 NIGHT VISION (F)
电磁视觉高亮电子设备 · 蓝绿色调
生物视觉高亮有机生命 · 红粉色调
夜视黑暗中视物 · 紫色调

设计要点 KEY FEATURES

1. 一键切换——E/Q/F 三个按键即时切换，无需进入菜单
2. 画面滤镜——每种模式施加全屏色彩分级，改变整个世界的外观
3. 物品高亮——对应类型的可互动物品以发光轮廓标识，非目标物品暗淡
4. 音效反馈——切换时伴随电子嗡鸣声，强化植入体激活感
5. 策略选择——不同谜题需要不同视觉模式，玩家需主动切换而非被动扫描
6. 视觉疲劳——长时间使用某种模式会产生轻微画面扭曲，暗示植入体副作用
对 Fire Roach Killer 的启示：可考虑加入类似的视觉模式切换（如热成像模式高亮蟑螂、电磁模式显示陷阱），用画面滤镜替代传统 UI 标识。

布局方案 LAYOUT

ESC 呼出的暂停菜单同样遵循极简终端风格——游戏画面不冻结（保持背景可见），菜单以半透明黑色遮罩 + 等宽字体列表呈现。选项包括：继续 / 设定 / 返回主菜单 / 退出游戏。

设计要点 KEY FEATURES

1. 不冻结背景——暂停时游戏画面仍可见，不打破沉浸感
2. 暗化遮罩——半透明黑色 overlay，让菜单文字清晰但不完全隔绝世界
3. 等宽终端字体——与主界面保持一致，冰冷、机械、无情感
4. 无装饰——没有按钮背景、没有图标、没有渐变，只有文字
5. 选中态——文字变为霓虹蓝 + 轻微发光，极简到极致
对 Fire Roach Killer 的启示：暂停菜单可学习这种"不冻结 + 暗化遮罩"设计，保持紧张感，同时用极简终端风格统一整体美学。

⑦ 环境 AR 叠加层 ENVIRONMENTAL AR OVERLAYS

布局方案 LAYOUT

Observer 最独特的 UI 元素——环境中的 AR 全息广告与信息标识。克拉科夫贫民窟的每个角落都充斥着 Chiron 公司的全息投影、反乌托邦标语、霓虹招牌。这些不仅是装饰，更是叙事工具。

设计要点 KEY FEATURES

1. 叙事性装饰——每个广告、每条标语都在讲述世界观（如"Chiron: 你的意识，我们的未来"）
2. 全息投影质感——半透明的、闪烁的、带有扫描线瑕疵的投影
3. 语言混合——招牌同时使用中文、英文、波兰文，暗示全球化崩塌后的语言混杂
4. 色彩暴力——高饱和霓虹色（粉、蓝、绿）与衰败环境的灰暗形成强烈对比
5. 动态元素——全息广告持续旋转/闪烁，让静态环境充满生命力
6. 可互动性——部分 AR 标识可扫描获取额外线索，将装饰转化为玩法

⑨ 不存在的系统 ABSENT SYSTEMS

Observer 没有这些 N/A

作为线性叙事恐怖游戏，Observer 主动摒弃了传统 RPG 的诸多系统。这种"减法设计"本身就是其 UI 哲学的核心——越少越好，直到只剩下恐惧。

商店系统——无货币、无交易、无装备购买。Daniel 是警探，不是冒险者
天赋/升级——无技能树、无属性加点。能力固定（三种视觉模式），叙事驱动
成就系统——无弹出式成就。PlayStation 奖杯存在但游戏内完全不可见
传统图鉴——无敌人图鉴或物品百科。收集品是世界观文档，非游戏机制
等级/经验——无角色成长。整个游戏就是一场无法升级的噩梦

减法设计的启示 LESSONS

1. 系统存在的目的——每个 UI 系统必须回答："它服务于什么情感？"
2. 恐怖 = 未知——血条给了玩家虚假的安全感，没有它，每次受伤都是恐惧
3. 沉浸 > 便利——暂停游戏查看地图是便利的，但不暂停的 AR 面板是沉浸的
4. 统一美学——所有 UI 共享同一套视觉语言（终端字体、霓虹色、扫描线）
5. 世界即界面——最好的 UI 是玩家感觉不到它的存在
核心启示：Fire Roach Killer 可以考虑在特定模式/难度下隐藏部分 HUD，用环境视觉反馈替代数字显示，增强生存恐怖感。

霓虹红 #FF2A6D——生物视觉主色、警告、危险、血液
霓虹蓝 #05D9E8——电磁视觉主色、科技、信息、选中态
霓虹紫 #BD00FF——夜视主色、神秘、幻觉、未知
机构黄 #FFB300——重要信息高亮、可收集品、关键线索
背景黑 #080A0F——比纯黑稍暖的深蓝黑，容纳霓虹而不刺眼

质感与特效 TEXTURE

CRT 扫描线——所有 UI 元素叠加细微水平扫描线，模拟老旧显示器
色差偏移——文字与图像边缘有轻微的 RGB 分离，模拟廉价 AR 设备
噪点颗粒——暗部区域有细微噪点，增强胶卷/监视器质感
发光 bloom——霓虹色元素带有柔和光晕，模拟真实光源
故障 glitch——切换视觉模式或精神负荷过高时，画面出现撕裂与偏移
暗角 vignette——屏幕四角轻微压暗，聚焦中央视野
关键原则：所有特效都服务于"廉价植入体的瑕疵感"——不是未来科技的光滑完美，而是贫民窟里勉强能用的破烂货。

字体系统 TYPOGRAPHY

等宽终端字体——所有 UI 文本使用 monospace，模拟 DOS/终端界面
无衬线英文——环境中的英文标识使用简洁无衬线体
混合语言——招牌与广告同时使用中文、英文、波兰文
字号层级——标题 18-24px / 正文 12-14px / 辅助 9-10px
字符间距——标题 letter-spacing: 0.15em，营造疏离感

声音设计 AUDIO

视觉模式切换——每种模式有独特的电子嗡鸣声（电磁=高频，生物=低频，夜视=中频）
交互反馈——拖拽物体时的机械摩擦声，强化物理存在感
受伤状态——无血条，通过心跳声 + 耳鸣传达伤害程度
神经入侵——声音彻底崩解，低语、尖叫、电子噪音交织
环境音——霓虹灯的电流声、远处的哭喊、雨声，构成声景叙事

设计令牌 DESIGN TOKENS

提取 Observer 的核心设计语言，形成可直接应用于 Fire Roach Killer 的设计令牌。

CSS 变量 TOKENS

:root{
  /* 背景 */
  --bg:#080a0f;        /* 深蓝黑背景 */
  --panel:#11141d;     /* 面板底色 */
  --line:#1e2333;      /* 边框线 */

  /* 文字 */
  --ink:#d8dce6;       /* 主文字 */
  --ink-dim:#6b7285;   /* 次要文字 */

  /* 霓虹色 */
  --neon-red:#ff2a6d;  /* 警告/生物 */
  --neon-blue:#05d9e8; /* 科技/选中 */
  --neon-violet:#bd00ff;/* 神秘/夜视 */
  --neon-amber:#ffb300;/* 高亮/重点 */

  /* 暗色底 */
  --dim-red:#5c1a2e;
  --dim-blue:#0a3a40;
  --dim-violet:#2d0040;
}

间距与圆角 SPACING

:root{
  /* 圆角：极简直角或小圆角 */
  --r-sm:2px;   /* 按钮/标签 */
  --r-md:4px;   /* 卡片/面板 */
  --r-lg:6px;   /* 大模块 */

  /* 间距 */
  --s-xs:6px;   /* 行内间距 */
  --s-sm:10px;  /* 组件内部 */
  --s-md:18px;  /* 组件之间 */
  --s-lg:28px;  /* 区块之间 */

  /* 边框 */
  --b:1px solid var(--line);
  --b-accent:1px solid rgba(5,217,232,.3);
}

组件规范 COMPONENTS

按钮——无背景，纯文字 + 霓虹蓝 hover 发光。选中态文字变色 + 轻微阴影
卡片——深色背景 + 1px 边框 + 顶部 2px 霓虹色边线，无阴影
列表——等宽字体 + 简单边框分隔，无斑马纹、无 hover 背景
输入框——透明背景 + 底部 1px 线 + 霓虹蓝 focus 发光
进度条——纯色填充，无渐变、无圆角、无动画（或极慢脉冲）
标签/徽章——1px 边框 + 小圆角(2px) + 霓虹色文字，无背景填充

动效规范 MOTION

切换视觉模式——0.3s ease 色彩渐变 + 电子嗡鸣音效
呼出 AR 面板——0.2s 透明度淡入，无缩放/位移
交互标签浮现——0.15s 淡入，看向目标时即时出现
受伤反馈——屏幕边缘红色渐变 0.5s 脉冲，无弹窗
精神负荷警告——画面随机 glitch 抖动，无规律
全息广告——持续缓慢旋转/闪烁，不吸引注意力
设计箴言：Observer 的 UI 设计证明了"减法的力量"——通过移除而非添加来创造沉浸。Fire Roach Killer 可以借鉴这种哲学：在特定模式（如"硬核模式"）下隐藏更多 HUD 元素，用环境视觉反馈替代数字显示，让玩家通过感觉而非阅读来理解游戏状态。霓虹色不是装饰，而是信息的载体；黑暗不是空白，而是恐惧的容器。
