SEC.01

废土生存系

Post-Apocalyptic Survival

四款游戏共享一种"文明废墟中拾荒"的视觉气质：锈蚀金属、手写标记、磷光绿屏、胶带修补。它们的 UI 不是被"设计"出来的，而是被"使用过的"——每个界面都带着磨损与岁月，让玩家在打开菜单的瞬间就感受到物资匮乏与生存压力。对应界面：商店卡片边框底色、战斗沉浸 HUD、主界面机械按钮、图鉴磨损做旧。

辐射系列 PIP-BOY CRT

核心语言：磷光绿 CRT 终端 + 机构黄双色调。Pip-Boy 3000 是腕戴式信息设备，屏幕以阴极射线管的磷光绿为主色（#30FF50），辅以 Vault-Tec 机构黄（#FFB000）作为强调色。等宽字体、扫描线叠层、网格边框将信息"物理容器化"——每个面板都有硬边框和可见角接，信息像档案柜里的实体卡片一样被装入方框。表面不做"干净"处理——锈迹、污渍、划痕是系统性的"受控腐蚀"层，与乐观的机构黄共同构成"封存的核时代乐观主义"美学。

地铁系列 GAS MASK POV

核心语言：防毒面具视角内的沉浸式 diegetic HUD。地铁系列将所有 UI 信息嵌入角色佩戴的防毒面具圆弧内——计时器、过滤器状态、弹药数都贴合在面具镜片的物理曲面上。镜片会因呼吸起雾、因战斗破裂，玩家需要手动擦拭。手电筒照明是交互的核心：光锥扫过黑暗时才显出可读信息，黑暗中 UI 也在暗处。弹药数贴合在面具的物理弧面上，背包查看需要低头"看向"角色胸前——所有交互都是 diegetic（叙事内嵌）的，UI 不叠加于画面之上，而是存在于角色的物理身体上。

潜行者 PDA INDUSTRIAL

最后生还者 HAND-DRAWN SURVIVAL

核心语言：手写涂鸦 + 胶带修补 + 极简克制 HUD。顽皮狗的 UI 哲学是"少即多"——步行时 HUD 几乎完全消失，可交互物品仅以一条白色细线圈标示。制作菜单的素材与成品分列两栏，当前物品高亮为白底灰透明，克制到极致。HUD 圆形生命条贴边放置，不干扰画面中心。UI 的每个元素都像"用胶带临时粘上去的"，带着物资匮乏的真实手感。Part II 进一步极简化：圆形生命条更细、更贴边，制作菜单更克制—— Naughty Dog 的设计哲学是"UI 越少，沉浸越深"。

废土系共性：四款游戏都将 UI 视为世界观的一部分而非叠加层——Pip-Boy 是角色佩戴的实体设备，防毒面具是玩家眼前的物理镜片，PDA 是变异区里的故障终端，制作菜单是末日幸存者的临时工作台。UI 的磨损、锈蚀、手写痕迹不是装饰，而是叙事。核心配色围绕磷光绿/琥珀黄/铁锈棕/近黑展开，低饱和度营造"使用过的"真实感。
SEC.02

赛博科幻系

Cyberpunk Sci-Fi

四款游戏代表"技术渗透肉体"的视觉谱系：全息投影边框、霓虹配色、人体扫描、神经可视化。它们的 UI 不是屏幕上的层，而是空间中的光——浮空、故障、扫描、入侵，每帧都在暗示"你的身体已被数据化"。对应界面：战斗全息 HUD、商店终端质感、关卡数据面板、图鉴 3D 扫描展示。

赛博朋克 2077 HOLO GLITCH

核心语言：全息投影浮空 UI + 故障艺术 + 红青双色霓虹。夜之城的 UI 不贴在屏幕上，而是悬浮在空气中——电话面板、任务日志、对话选项都是全息投影，边缘带 chromatic aberration（色差）和 scanline 故障条纹。血量/护甲以青色光弧呈现，黑客入侵时的代码瀑布与 ICE 防御层级用红色警告。Glitch 效果不是随机损坏，而是"数字世界的不稳定存在"的视觉隐喻。血量/护甲以青色光弧呈现，技能栏图标带霓虹发光边框，对话选项以全息文字浮在角色面前。整个 UI 体系暗示：在 2077 年的夜之城，信息不是被"显示"的，而是被"投影"在空气中的光。

看门狗系列 PHONE AR HACK

SEC.03

复古终端系

Retro Terminal

四款游戏从不同年代提取"过时技术作为美学归宿"的设计语言：DOS 绿字黑屏、极简红白黑、70 年代磁带科幻、PS1 时代低多边形 CRT。它们证明了一件事——技术限制本身就是一种设计风格，而且是情感最强的那种。对应界面：成就终端字体、战斗警告色、主界面复古按钮、全局扫描线特效。

Pony Island DOS GREEN-ON-BLACK

核心语言：老式 DOS 界面 + 黑底绿字 + 伪代码装饰。Pony Island 把玩家关进一台被恶魔附身的街机里，整个游戏以 DOS 操作系统的外壳运行。绿底黑字（实为黑底绿字 #30FF50）的终端窗口、伪代码命令行、灰度像素小马与故障图像混合——它用最原始的计算机界面语言制造恐怖。玩家需要"修改游戏代码"来逃出，代码编辑界面以伪汇编语言呈现，无需编程知识但充满"我在黑入系统"的紧张感。恶魔会通过修改游戏代码来阻挠你——UI 本身就是战场。

Alien: Isolation 70s RETROFUTURE

核心语言：70 年代复古未来 + 琥珀 CRT + 磁带存档机。《异形：隔离》把 1979 年雷德利·斯科特电影的视觉语言重建为完整设计系统：粗壮等宽终端字体、琥珀磷光（#FFB000）与绿色双色调、扫描线雾化、闪烁光标——全部呈现在永远不干净的 CRT 底色上。动作追踪器以模拟雷达圆扫描呈现，存档用磁带录音机，开门用菲林扫描仪——每一台设备都"有重量、有气味、有年代"。动作追踪器只显示移动物体的距离方向而非精确位置——如果异形停止移动，它就从屏幕上消失。这种"不完整信息"本身即是恐怖的引擎。

SEC.04

独立策略系

Indie & Strategy

四款独立游戏代表了"信息即设计"的极致：极简像素战棋网格、横版卷轴状态栏、工业管道建造面板、竖屏卡牌遗物列表。它们的 UI 不做氛围渲染，只做一件事——把信息用最少的像素最清晰地推到你眼前。对应界面：战斗竖屏信息排布、顶部状态栏、商店列表卡片、图鉴网格列表切换。

Into the Breach PIXEL GRID INFO

核心语言：极简像素战棋 + 清晰网格信息 + 完全透明博弈。开发者 Matthew Davis 和 Justin Ma 在测试中发现"必须把'谁在做什么'展示得特别清楚"——于是所有攻击以循环抛物线/点线/箭头标注，敌人意图在回合开始前完全公开。8×8 小网格让每一步都是精密推演。UI 的最高追求是"零认知负担"——你需要的信息全在屏幕上，一目了然。攻击轨迹用不同线型区分：抛物线=抛射、点线=远程、箭头=近战推进，颜色编码区分友/敌/建筑。

SEC.06

设计检查清单

Design Checklist

将 16 款游戏的调研结论提炼为可操作的检查项——在落地任何界面模块前，用这组问题自检。

① 色彩一致性

□ 是否从四系中选定一个主范式（废土/赛博/复古/独立）作为全局色彩基底？
□ 辅助色是否限定在 3–5 色以内，且有明确语义（友方/敌方/警告/资源）？
□ 是否避免了跨范式混用（如废土锈蚀 + 赛博霓虹 = 视觉冲突）？
□ 色板是否已在所有界面模块（商店/战斗/图鉴/成就/关卡）中统一？

② 字体策略

□ 标题与正文是否双字体系统（如粗壮衬线标题 + 等宽正文）？
□ 等宽字体是否用于数值/终端/代码场景？
□ 像素字体是否仅用于特定复古模块（如成就/全局特效）？
□ 字号层级是否 ≤ 4 级，避免碎片化？

③ 质感与氛围

□ 卡片边框是否带有物理质感（锈蚀/铆钉/磨损/胶带）而非纯平面？
□ 扫描线/故障特效是否仅在特定场景触发（加载/事件/Boss），不全局常驻？
□ Diegetic 元素（面具/PDA/终端）是否融入世界观而非浮于其上？
□ 是否有至少 1 处"可交互的物理质感"（擦拭镜片/磁带存档/按钮按压）？

④ 信息层级

□ 战斗 HUD 是否遵循 Into the Breach 原则——所有决策所需信息一目了然？
□ 状态栏是否贴边放置（Dead Cells 模式），不遮挡核心视野？
□ 图鉴是否支持网格/列表双视图切换（Slay the Spire 模式）？
□ 数值展示是否简洁到极致——每个数字都有语义图标？

⑤ 界面模块映射

□ 商店界面是否参考了 辐射网格边框 + 看门狗终端面板？
□ 战斗 HUD 是否融合了 地铁沉浸感 + 赛博全息发光 + Superhot 警告色？
□ 图鉴是否采用了 Deus Ex 数据面板 + Observer 3D 扫描布局？
□ 成就系统是否使用了 Pony Island 终端字体 + 乱码装饰？

⑥ 全局一致性

□ 所有模块是否共享同一色板、字体、边框圆角、间距系统？
□ Hover/Active/Disabled 状态是否四系统一（如统一用琥珀色高亮）？
□ 动画时长是否≤ 0.3s（即时反馈），避免过度装饰？
□ 移动端是否做了 触控优化（目标 ≥ 44px，禁用 hover 位移）？

终极原则：16 款游戏给出的最大启示是——UI 不是叠加层，UI 是世界观的延伸。辐射的 Pip-Boy 是角色佩戴的设备，地铁的面具是玩家眼前的物理镜片，潜行者的 PDA 是变异区里的故障终端。无论选择哪个范式，让 UI 成为游戏世界的一部分而非浮于其上的界面，才是最好的美术设计。
UI ART DESIGN ARCHIVE

本档案调研全网 16 款标志性游戏的 UI 美术设计，萃取四范式的视觉语言、交互范式与氛围构建手法，映射至塔防游戏五大界面模块。信源截至 2026 年 8 月。
