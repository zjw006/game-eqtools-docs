UI STYLE ANALYSIS · ALIEN: ISOLATION

Alien: IsolationCreative Assembly · 1970 年代复古未来主义的 CRT 终端美学

Creative Assembly 打造的生存恐怖杰作。玩家扮演 Amanda Ripley，在被遗弃的塞瓦斯托波尔空间站中躲避异形。其 UI 设计是一套完整的「复古未来」设计系统——核心主题是「黑匣子」：运行在过时显示技术上的过时电脑系统。通过琥珀色/绿色 CRT 荧光、VHS 失真、扫描线与闪烁模糊，将 1979 年原版《异形》电影的视觉遗产转化为一种持续有效的游戏 UI 风格。UI 设计师 John McKellan 率团队获取了 20th Century Fox 提供的 3TB 电影幕后资料，包括蓝图、连续性照片和概念艺术。这不是「复古风」——这是低保真即美学。

开发商 Creative Assembly
首发 2014
视觉参考 Alien 1979
核心主题 黑匣子
UI 类型 Diegetic 为主
SEC.01

游戏概述 GAME OVERVIEW

Alien: Isolation 的 UI 将过时技术转化为美学风格——低保真即美学，过时技术是设计语言而非缺陷。

01

复古未来 CRT

琥珀色/绿色荧光模拟老式终端显示。扫描线产生雾化、模糊和旧显示器质感——文字像「在脏玻璃上发光」，而非光洁的扁平界面。

02

Diegetic UI 为主

运动追踪器、终端、录音机等界面元素存在于游戏世界中。玩家通过实体设备获取信息，而非悬浮叠加的数字面板。沉浸感被推至极致。

03

极简 HUD

刻意减少屏幕信息干扰。生命指示器左下角尺寸很小，无红色闪烁或夸张血条。玩家依靠环境、声音和运动追踪器判断危险。

SEC.02

设计哲学 DESIGN PHILOSOPHY

Alien: Isolation 的 UI 哲学可归纳为「低保真即美学」——过时技术不是尴尬，而是美学归宿。文字、扫描线、闪烁与 CRT 辉光共同营造「文字是物理终端屏幕发出的信息」的感觉。

黑匣子概念 BLACK BOX

核心主题——运行在过时显示技术上的过时电脑系统
叙事服务——让玩家理解原版《异形》与本作之间的 15 年时空关系
3TB 资料——获得 20th Century Fox 提供的电影幕后资料（蓝图/连续性照片/概念艺术）
used universe——Ron Cobb/Roger Christian/Ridley Scott 奠基的「使用过的宇宙」美学

Diegetic UI DIEGETIC

运动追踪器——存在于游戏世界中的实体设备，玩家手持，占据较大空间
终端——空间站中的 CRT 终端可阅读日志/档案/音频记录
Rewire 系统——部分安装在墙上，允许从远处控制环境设备
音频日志——通过老式录音设备播放（磁带/开盘式录音机）
非 Diegetic 辅助——成就/任务选择等采用更平台化的功能设计
SEC.03

界面分析 INTERFACE ANALYSIS

逐项分析 10 个核心界面元素的视觉风格与设计逻辑。

① 加载界面 / 标题段落 LOADING / TITLE SEQUENCE

参照原版电影——参照 1979 年《异形》标志性标题序列，匹配时间轴/模糊边缘/电影画面特性/渐隐后蓝色色调
视觉——苍白、模糊且像素化的光柱从黑暗中升起，其他光束快速交替切入勾勒更大轮廓
节奏——慢速、逐帧推进，与原版《异形》慢节奏恐怖氛围一致
35mm 胶片效果——扫描线/模糊边缘/低分辨率像素化
独白——Sigourney Weaver 重新录制原版《异形》结尾独白作为引子
① 加载 / 标题序列 · 1979 电影美学 + 35mm 胶片（风格示意图）

② 主菜单 MAIN MENU

布局——由游戏中使用的物品组成，红药丸为最醒目元素，显示可控制角色图片（Amanda Ripley/Fran/Mr. Midnight）
底色——黑暗、近乎纯黑，与 CRT 终端暗光氛围一致
高光色——红色药丸利用红色在暗背景上的强对比度
字体——等宽体（monospaced），粗壮、方块化，唤起电传打字机输出与早期终端字体感
控制键标注——绿色、非比例字体，带有强烈衬线，与早期终端显示器风格一致
复古未来——通过做旧/模糊/闪烁效果融入复古未来感，菜单查看时会闪烁，营造 VHS 录像带观感
② 主菜单 · 游戏物件 + 红药丸 + VHS 闪烁（风格示意图）

③ 战斗界面 / HUD COMBAT HUD

极简设计——刻意减少屏幕信息干扰，让玩家感觉 HUD 存在于游戏世界中的实体设备
运动追踪器——屏幕底部手持，介于 Ash 粗制设备与海军陆战队军事化硬件之间，仅显示接近距离不显示精确位置
追踪器信噪比——只告诉你「有什么东西在那里」，不告诉你具体在哪里
尺寸影响——追踪器足够大，装备时无法同时持枪
健康指示器——左下角尺寸很小，最不显眼的 HUD 元素之一
弹药——右下角显示弹药数量
手电筒——独立电量指示器
目标更新——屏幕显示目标更新信息与方向性指示器
③ 战斗 HUD + 运动追踪器 · 极简 HUD + Diegetic 设备（风格示意图）

④ 关卡 / 任务选择 MISSION SELECTION

地图界面——采用 CRT 终端风格，带有闪烁和模糊效果
收集品——任务选择界面与地图关联，可获取错过的收集品
目标日志——低干扰、信息量少、仅显示必要内容
④ 关卡 / 任务选择 · CRT 终端地图 + 闪烁模糊（风格示意图）

⑤ 商店 / 物品制作 CRAFTING

径向菜单——Q 键打开，武器和物品以图标围绕中心排列成圆形
显示内容——当前持有物品/弹药补给/调谐器等级/切割火炬等级/手电筒电池
制作过程——手动选择每个组件，故意设计得繁琐和笨拙
制作配方——医疗包：SCJ 注射器 + Compound B + Bonding Agent + 10 Scrap
可制作物品——医疗包/EMP 地雷/烟雾弹/闪光弹/管道炸弹/噪音发生器/莫洛托夫
设计哲学——强调「手续繁琐」的体验，与生存恐怖氛围相契合
⑤ 物品制作 · 径向菜单 + 手续繁琐（风格示意图）

⑥ 武器升级 / 工作台 UPGRADE BENCH

工作台升级——存在工作台升级系统，如等离子切割器的升级台
升级方式——需在特定工作台上完成，而非独立技能树界面
视觉变化——升级后武器可能有不同视觉效果（如普通→离子切割器）
图纸/蓝图——升级系统与终端和任务流程紧密相关
安全访问——终端输入特定代码可解锁内容（如 6832 打开安全百叶窗）
⑥ 升级工作台 + ⑧ 数据终端 · 工作台 + CRT 终端（风格示意图）

⑦ 成就系统 ACHIEVEMENTS

平台通用——采用统一图标样式，与 Xbox/PS 平台成就系统一致
设计缺口——成就界面未采用 CRT 终端/琥珀色/绿色终端美学，更偏功能化
内容——Not the First（关闭信标）/Hide. Run. Survive.（不被杀死）/One Shot（通关未死亡）
ID 标签——All Taken/搜寻者成就与收集 ID Tag 相关

⑧ 数据库 / 终端 / 收集品 CODEX / TERMINALS

Nostromo 终端——空间站中大量终端可互动，阅读日志/档案/音频记录
CRT 风格——终端屏幕呈现 CRT 终端风格，扫描线/模糊/闪烁
档案日志——提供塞瓦斯托波尔空间站事件背景信息
音频日志——通过老式录音设备播放（磁带/开盘式录音机）
Rewire 系统——部分安装在墙上，从远处控制环境设备（灯光/通风）
ID 标签——收集品，可在地图菜单查看，每个有独立名称

⑨ 战斗生命条 HEALTH BAR

位置——左下角，尺寸很小
设计——极小、低干扰的 HUD 元素，非大面积高饱和度设计
色彩——遵循 CRT 终端美学：绿色/琥珀色荧光色调，背景黑暗
无红色闪烁——无常见「屏幕变红」死亡预警效果
设计意图——玩家依靠环境、声音和运动追踪器判断危险，而非明确视觉伤害反馈

⑩ 视觉特效 VISUAL EFFECTS

CRT 与 VHS CRT / VHS

扫描线——核心视觉特征，产生雾化、轻微模糊和旧显示器质感
VHS 失真——使用旧录像机和 Betamax 机器录制游戏视频，获得真正复古感
闪烁模糊——菜单和地图查看时会闪烁，强化老式录像带观感
CRT 辉光——文字和界面呈机械打印感，屏幕表面有可见污渍和磨损
脏玻璃效果——文字像「在脏玻璃上发光」，而非光洁现代扁平界面

运动追踪器 MOTION TRACKER

雷达显示——显示外星生物接近距离，不显示精确位置
数字读数——左下角数字越小表示威胁越近
ping 声效——独特 ping 声效，黑暗中效果尤为明显
同步闪烁——外星生物靠近时追踪器同步闪烁并频繁亮起
环境模糊——查看追踪器时占据较大屏幕空间，环境会模糊

色彩调色板 COLOR PALETTE

琥珀色/橙色——CRT 荧光色，模拟老式终端显示效果
绿色——Seegson 终端绿色荧光读数，用于信息读取
黑色/暗绿——CRT 底屏颜色，深色、脏污、近乎纯黑
红色——高优先级警告和关键物品（如红药丸）
整体呈现——高对比度、低分辨率的 CRT 荧光效果
⑩ CRT/VHS 视觉特效 + Diegetic 设备 · 扫描线 + 脏玻璃 + 实体设备（风格示意图）

总结：Alien: Isolation 的 UI 是一套完整的「复古未来」设计系统。它将 1970 年代科幻电影的视觉遗产——琥珀色 CRT 荧光、VHS 失真、扫描线、脏玻璃效果——转化为一种持续有效的游戏 UI 风格。运动追踪器、终端和录音机等 Diegetic 设备让玩家在游戏世界中获取信息，而非依赖悬浮叠加的数字面板。低保真即美学——过时技术不是缺陷，而是设计语言。这套系统成为复古未来主义在游戏设计中的经典范例。
