UI STYLE ANALYSIS · DEUS EX SERIES

Deus Ex 系列Eidos Montréal · 赛博文艺复兴与黑金美学

Eidos Montréal 打造的赛博朋克 RPG 系列。总监 Jonathan Jacques-Belletête 提出 Cyber Renaissance（赛博文艺复兴）设计方向，将 16 世纪文艺复兴艺术与赛博朋克 noir 融合。其标志性的黑金对比——黑色代表末世/阴谋/地下世界，金色代表人性/希望/未来——构成了游戏 UI 的核心视觉语言。方形几何主导、扁平化设计、HUD 斜向布局与AR 增强现实理念共同塑造了独特的赛博文艺复兴界面风格。当 Jensen 使用增强功能时，UI 成为他身体感知的一部分，而非简单的屏幕叠加。

SEC.01

游戏概述 GAME OVERVIEW

Deus Ex 系列将「人类增强」主题通过界面本身传达——当 Jensen 使用增强功能时，UI 成为他身体感知的一部分。

01

黑金对比

黑色=末世/阴谋/地下世界，金色=人性/希望/未来。金色不仅用于文字，也用于边框、装饰线和按钮高光，是 Icarus 神话的视觉化。

02

方形几何

所有 UI 元素采用近乎方形的轮廓，边角几乎无圆角，以切角/截断边角呈现，形成整齐、干练的「企业化」视觉。扁平化设计不依赖拟物阴影。

03

AR 增强现实

HUD 元素的设计意图是「感觉像增强现实」。管理武器时 UI 附着在武器上并追踪它；Smart Vision 是增强 AR 视觉系统。

SEC.02

设计哲学 DESIGN PHILOSOPHY

Deus Ex 的 UI 哲学围绕「Cyber Renaissance」展开，通过黑金主色调、方形几何、扁平化与 AR 理念塑造独特视觉风格。

赛博文艺复兴 CYBER RENAISSANCE

设计方向——总监 Jacques-Belletête 明确提出将 16 世纪文艺复兴与赛博朋克 noir 融合
Icarus 神话——金色代表人性接近太阳的追求，黑色代表末世与地下世界
硬质塑料质感——平坦、均匀、低对比度光照使 UI 呈现硬质哑光塑料质感
HUD 斜向布局——Human Revolution 的 HUD 向屏幕中心倾斜，强化视线焦点

AR 增强现实理念 AR OVERLAY

UI 即身体——Mankind Divided UI Director 表示 HUD 元素「感觉像增强现实（AR）」
武器追踪——管理/调试武器时 UI 附着在武器上并追踪它
Smart Vision——增强 AR 视觉系统，通过色彩重映射/几何高亮/对象类型蒙版化高亮威胁与设备
骇入界面——抽象分形几何节点为核心，具有微距摄影般质感
SEC.03

界面分析 INTERFACE ANALYSIS

逐项分析 10 个核心界面元素的视觉风格与设计逻辑。

① 加载界面 LOADING SCREEN

视觉风格——延续黑金视觉语言，金色光泽、黑色背景与几何边框
动态元素——加载过程中出现与世界观一致的动态广告或场景元素，增强沉浸感
技术实现——Human Revolution 使用 Scaleform（Flash-based UI 中间件）+ C++ 后端 + ActionScript
① 加载界面 · 黑金配色 + 几何边框（风格示意图）

② 主菜单 MAIN MENU

布局——New Game/Load/Options/Developer Commentaries/Exit Game，通过暂停/主菜单进入
颜色——黑色底，金色文字/图标为主色调，金色文字在深色背景上呈现发光质感
几何化——菜单项之间有明确几何边界，金色用于边框/装饰线/按钮高光
视觉特点——硬朗、有序、科技感强；扁平化、低圆角特征
② 主菜单 · 金色文字 + 方形几何边框（风格示意图）

③ 战斗界面 / HUD COMBAT HUD

Human Revolution——左上角生命值，左下角小型雷达/威胁等级，右下角武器/弹药，准星红=敌对/灰=中立/绿=友好
Mankind Divided——左下角蓝色能量条，右下角绿色生命条，右上角雷达/地图，左上方 NPC 通信对话框
AR 理念——HUD 元素「感觉像增强现实」，管理武器时 UI 附着在武器上并追踪它
Smart Vision——色彩重映射 + 几何高亮 + 对象类型蒙版化，高亮威胁/战利品/设备/安全系统
③ 战斗 HUD · AR 叠加 + 金蓝配色（风格示意图）

④ 任务 / 关卡选择 MISSION LOG

Human Revolution——暂停菜单多标签页：Inventory/Map/Augs/Media Log/Quest Tracking
Mankind Divided——任务目标显示在屏幕左侧，任务风格可选择强攻或潜入
BREACH 模式——独立跑酷和骇入挑战模式，含排行榜和升级系统

⑤ 商店 SHOP

Mankind Divided——商店购买 Story Mode 装备及 DLC 内容，入口位于暂停菜单
物品栏——查看/检查/移动/调整/丢弃物品，可分配到热键
视觉——延续整体菜单的几何化、扁平化风格

⑥ 天赋 / 增强功能升级 AUGMENTATION

网格化升级——不采用传统技能树，以有序方形网格呈现，按身体部位分组（上肢/下肢/头部等）
Praxis Kit——Praxis Point 用于解锁或升级增强功能，所有升级开始时即可选择
视觉——金黑配色、硬朗几何线条、低圆角设计，每个方格代表一个可解锁增强功能
Mankind Divided——增强功能系统重新设计，更多增强功能与更深 RPG 机制
⑥ 增强功能 + 物品栏 · 网格升级 + 几何物品栏（风格示意图）

⑦ 成就系统 ACHIEVEMENTS

Mankind Divided——约 50-81 个成就（不同来源口径不一），几乎全部可能错过
外部系统——通过 Xbox/PS/Steam 平台成就列表追踪
设计——外部进度追踪系统，显示奖杯/成就/奖励状态

⑧ 数据库 / 邮件 / 收集 CODEX / DATABASE

数据库——Mankind Divided Database 标签页收集所有电子邮件/PDA/电子书/故事物品/BREACH 软件组件
电子邮件——游戏内大量邮件作为叙事和世界观补充
新闻系统——Picus News 贯穿游戏，内容随游戏进展和玩家选择变化
BREACH——独立骇入挑战模式，含排行榜与升级系统
⑧ 全息数据库 · AR 面板 + 金色读数（风格示意图）

⑨ 战斗生命条 HEALTH BAR

Human Revolution——生命值左上角，100 时停止自然恢复，虚线三角形=潜在生命值（食物/饮料可达 200），受伤时血条闪烁红色
能量条——驱动主动增强功能，耗尽后需再生或获取新能量
Mankind Divided——蓝色能量条左下角，绿色生命条右下角
最大能量——部分增强功能降低最大能量值，白色线条表示，Bio Cell 可重置

⑩ 视觉特效 VISUAL EFFECTS

色彩体系 COLOR

金色/琥珀色——人性、希望、未来，文字/图标/高光/增强功能 UI
蓝色——能量、AR 系统、Hack 网络，能量条/Smart Vision/骇入界面
绿色——生命、友好、正常状态，生命条/友好目标/正常网络节点
红色——敌对、威胁、警报，敌对目标/被黑客攻击节点
HR → MD 转变——MD 减少黑金，转用蓝色+灰色营造更压抑氛围

全息与骇入 HOLOGRAM

全息设备——全息桌和屏幕界面采用未来主义 AR 视觉风格
骇入界面——抽象分形几何节点，部分节点图标化，微距摄影质感
Smart Vision——色彩重映射 + 几何高亮 + 对象类型蒙版化
UI 团队——设计了邮件/新闻/骇入/任务简报/安全系统等角色使用的界面
⑩ 骇入 + Smart Vision · 分形节点 + AR 视觉（风格示意图）

总结：Deus Ex 系列围绕「Cyber Renaissance」展开，通过黑金主色调、方形几何、扁平化与 AR 增强现实理念，塑造了独特的赛博文艺复兴界面风格。Human Revolution 以黑金为核心象征，Mankind Divided 因叙事基调转向更多使用蓝色与灰色——但整个系列始终传达一个核心理念：当人类被增强，界面也成为身体的一部分。
