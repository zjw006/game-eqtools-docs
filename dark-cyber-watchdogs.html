看门狗 系列Ubisoft · 从 DOS 极简到智能手机操作系统的黑客 UI 演变

Ubisoft 打造的开放世界黑客动作系列。从 2014 年芝加哥的阴暗沉重（《看门狗 1》），到 2016 年旧金山的明亮街头（《看门狗 2》），再到 2020 年伦敦的抵抗组织（《看门狗：军团》），三作核心 UI 始终围绕「手机即武器」这一概念展开——玩家掏出智能手机即可控制整座城市。其 UI 从DOS/命令行式极简，演变为智能手机操作系统拟真，再到街头抵抗组织视觉体系，贯穿始终的是故障美学、网络线、数字噪点与 DedSec 品牌视觉。

SEC.01

游戏概述 GAME OVERVIEW

看门狗系列将「黑客/数字反抗」主题转化为可交互的视觉语言。三作以智能手机为 UI 核心隐喻，通过故障美学、网络线与数字噪点营造「世界即界面」的沉浸感。

01

WD1 · DOS 极简

芝加哥阴暗色调，UI 采用「barebones」排版与 8-bit/DOS 编程字体，粗糙原始的 hack 感，与精致画面形成对比。圆形黑客模块 + Botnet Meter。

02

WD2 · 手机 OS

旧金山明亮街头，UI 参考 Android Material Design，所有功能包装为手机应用，环形技能选择器 + 三面板布局，融入涂鸦/故障艺术/ASCII 艺术。

03

Legion · 抵抗组织

伦敦街头抵抗，深色+红蓝霓虹对比，Mission App/Team App 基准统一视觉语言，Wheel Menu 选择角色与装备，可定制 HUD 元素。

SEC.02

设计哲学 DESIGN PHILOSOPHY

看门狗系列的 UI 哲学可归纳为「手机即武器，世界即界面」——玩家掏出手机即掌控城市，环境中散布的图标提示可黑客对象。

手机即武器 PHONE AS WEAPON

WD2 核心理念——Alexander Karpazis 强调智能手机是 WD2 UI 设计的核心交互体验
应用化功能——所有游戏功能（地图/任务/研究/商店）包装为手机应用图标
不暂停游戏——WD2 打开手机菜单时游戏不暂停，强化「随时随地掏出手机」感
模糊背景——智能手机应用使用模糊背景处理，保持一致外形和框架

世界即界面 WORLD AS UI

环境图标——WD1 环境中散布图标提示可黑客对象，世界自带接口感
网络线——黑客视觉效果以「网络线」形式展示数据连接，表现黑客复杂性
低干扰 HUD——三作均强调 HUD 集中在屏幕边缘，避免遮挡核心画面
可定制——Legion 支持开关 Mission Icons/Minimap/Enemy Health/GPS Line 等元素
SEC.03

界面分析 INTERFACE ANALYSIS

逐项分析 10 个核心界面元素的视觉风格与设计逻辑。

① 加载界面 LOADING SCREEN

WD2——中心进度条动画，加载过程在屏幕中心进行，与手机操作系统概念一致
整体设计——简洁、功能性，不使用复杂过场，强调「系统启动中」感
WD1 延续——DOS 式极简加载，像素化文字与原始计算质感
① 加载界面 · 中心进度条 + 手机启动概念（风格示意图）

② 主菜单 MAIN MENU

WD2——以智能手机界面为框架，类似手机桌面，选择应用图标进入功能模块
WD1——barebones 排版与图标，类似早期手机图标/8-bit/DOS 编程字体，「基本计算」质感
Legion——Mission App 与 Team App 基准设定统一菜单视觉语言
设计演变——从 DOS/命令行极简 → 智能手机 OS 拟真 → 统一应用框架
② 主菜单 · 智能手机 OS 拟真界面（风格示意图）

③ 战斗界面 / HUD COMBAT HUD

WD2——左下角小地图+快速槽，右下角能量槽（黑客攻击消耗），战斗时提供武器/弹药/目标/能量
Legion——追踪任务/小地图/已选武器及弹药/已选 gadget，更精简仅显示必要信息
WD1——武器状态/投掷物目标/手机电池/Focus 槽/小地图/Aiden 热度等级
准星——Legion 可自定义颜色/大小（100%-150%），支持色盲预设与对比度选项
设计目标——「随时可用、不打扰玩家」，游戏几乎可无 UI 运行，UI 只反映游戏状态

④ 关卡 / 任务选择 MISSION SELECTION

WD2 地图——类似 Google Maps 设计风格，地标建筑悬停显示说明文字，与手机应用系统融为一体
Legion——右键/操作进入任务列表，追踪任务并在地图查看，可调整 GPS Line 等辅助
WD1——目标/奖励/战斗/任务融入小地图和 HUD，强调信息即时可用
③④ 战斗 HUD + 任务地图 · 低干扰 + 类 Google Maps（风格示意图）

⑤ 商店 SHOP

WD2——在线商店目录风格，八家服装店各有品牌形象，600+ 件服装，与手机应用系统一致
Legion——货币 ETO 通过任务/快递/收集获得，购买后服装进衣柜，可预览/购买/更换外观
设计——强调「在线购物」熟悉感，融入黑客/城市文化品牌元素

⑥ 天赋 / 技能树 SKILL TREE

WD2 研究应用——通过手机中 Research App 进入，环形选择器选 7 个技能分支
三面板布局——环形选择器 + 技能列表 + 技能预览/说明区域，预览以动画循环展示
WD1——传统树状结构，升级方向：驾驶/黑客/物品制作/战斗
设计要点——WD2 的技能树是「研究」和「黑客」概念核心体现
⑤⑥ 商店 + 技能树 · 在线购物 + 环形研究（风格示意图）

⑦ 成就系统 ACHIEVEMENTS

Legion——219 个奖杯（含 18 个线上），按 Bronze/Silver/Gold/Platinum 分类
内容——故事完成/支线任务/科技点收集/装备购买/服装消费/收藏品收集
视觉——更偏功能化平台通用 UI，非完全融入游戏世界的 diegetic UI

⑧ 数据库 / 收集品 CODEX / COLLECTIBLES

WD1 黑客模块——圆形模块设计，与 Botnet Meter 相连，可作为快速黑客入口
WD2 手机应用——大量应用/图标/动画/加载内容/信息窗口，通过智能手机方式访问
环境接口——WD1 世界本身带有「接口化」感觉，图标散布提示可黑客对象

⑨ 战斗生命条 HEALTH BAR

Legion——HUD 选项含 Enemy Health Bars 开关，Combat Awareness Module 含 Detection Meter/Hit Detection/Blood Effect
低干扰——三作生命值显示均遵循低干扰原则，不使用大面积血条
可定制——可关闭/显示敌人血条，与其他 HUD 元素同等可定制

⑩ 视觉特效 VISUAL EFFECTS

故障美学 GLITCH

像素化文字——8-bit 字体、DOS 编程风格
网络线——节点连接图展示数据连接与黑客过程
信号干扰——屏幕闪烁、信号干扰效果
数字噪点——暗色背景+高对比度文本
霓虹光效——蓝色/青色霓虹，黑客时屏幕发霓虹蓝色能量
故障 Logo——像素化/故障风格标题与图标

DedSec 品牌视觉 DEDSEC

Logo——粗体无衬线字体+像素化/故障效果+几何/像素化动物图形
WD2 街头艺术——涂鸦/网络梗文化/ASCII 艺术/故障艺术融入 UI
Material Design——WD2 参考 Android Material Design 风格，简洁布局+高饱和度色彩
Legion 抵抗——深色/故障/街头抵抗/数字暴力的视觉语言
⑩ 故障美学 + DedSec 品牌视觉（风格示意图）
