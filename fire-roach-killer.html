SEC.01

现状分析

Current State Analysis

对游戏当前 8 个界面逐一截图分析，提炼优势与短板，为后续设计方案提供精准的改造依据。

① 主界面 MAIN MENU

现状：暗色废土厨房背景 + 居中持枪手图 + 双模式按钮 + 底排四功能入口。

优势：背景氛围到位，模式区分清晰
问题：按钮质感偏通用，缺乏世界观沉浸；图鉴图标与音频图标重复；重置按钮位置易误触
→ 参考 STALKER PDA + Alien Isolation

② 关卡选择 LEVEL SELECT

现状：纵向列表 10 关，每关含门图标、名称、描述、星级、奖励倍率。

优势：信息层级清晰，奖励递增有动力
问题：纯列表单调无分支路径感；缺少关卡预览图；视觉风格偏通用移动端
→ 参考 Fallout 网格 + STS 分支地图

③ 商店（补给站） SHOP

现状：顶部资金 → 分类商品列表（火枪/辅助）→ 底部库存栏。

优势：分类清晰，价格/效果/冷却信息完整
问题：卡片边框无质感；购买按钮不够醒目；库存栏与商店信息割裂
→ 参考 Fallout 网格 + 看门狗 ctOS

④ 天赋系统 TALENT

现状：三系 Tab（猛火/长枪/装备）+ 系别信息卡 + 树状节点结构 + 底部重置。

优势：前置依赖清晰，锁定条件明确
问题：节点连线偏简陋；系别色彩区分不够强烈；缺乏升级动效反馈
→ 参考 Deus Ex 改造树 + Dead Cells

⑤ 加载界面 LOADING

现状：巨型蟑螂 + 恐慌人群 + 标题 + 99% 加载条。

优势：视觉冲击力强，氛围营造到位
问题：加载条样式过于简单；加载文案未与世界观联动
→ 参考 Signalis CRT + 赛博 Glitch

⑥ 成就系统 ACHIEVEMENT

现状：进度条 + 全部/已解锁/未解锁 Tab + 成就列表卡片。

优势：筛选功能完善，进度可视化
问题：背景与卡片对比度不足；成就图标风格不统一；解锁动效缺失
→ 参考 Pony Island DOS + Fallout

⑦ 战斗 HUD COMBAT HUD

现状：战斗中实时显示血量、弹药、波次信息，底部技能/道具栏。

优势：核心信息覆盖全面，操作入口便捷
问题：HUD 元素缺乏沉浸感（非 diegetic）；状态栏占据视野过大；无面具/护目镜视角氛围
→ 参考 Metro 面具 + Cyberpunk 全息

⑧ 图鉴系统 CODEX

现状：累计击杀统计 + 2 列网格卡片 + 稀有度色分 + 击杀计数。

优势：14 种敌人全覆盖，稀有度色码有效
问题：卡片信息密度低；缺少敌人详细信息页；无网格/列表切换
→ 参考 Last of Us + Observer
核心问题总结：当前 UI 功能完备但视觉同质化严重——8 个界面共用同一套暗色卡片模板，缺乏世界观沉浸感（非 diegetic）、材质物理感（无锈蚀/铆钉/磨损）、色彩区分度（全黑底无语义色）。改造目标：让每个界面都成为灭虫者装备的延伸而非叠加层。
SEC.02

设计哲学

Design Philosophy

确立「Fire Roach Killer」的整体设计方向——不是另起炉灶，而是将现有的废土灭虫气质从背景延伸到界面。

范式定位 PARADIGM POSITIONING

主范式：废土生存系 PRIMARY

游戏核心是在废弃场所中用火焰武器消灭蟑螂——这与辐射、地铁、潜行者、最后生还者共享"文明废墟中拾荒生存"的气质。UI 应呈现受控腐蚀：锈蚀边框、磨损金属、磷光屏幕、胶带修补。每个界面都像是从废墟中捡回来的设备上运行的。

辅范式：复古终端系 SECONDARY

灭虫者的 PDA 设备运行在过时的工业终端上——磷光绿 CRT 扫描线、等宽字体、黑底绿字、机械按钮。这一范式用于成就系统（DOS 乱码装饰）和全局叠层特效（CRT 故障闪烁），在特定事件时触发增强戏剧性。

三大设计支柱 THREE DESIGN PILLARS

① 沉浸优先 DIEGETIC

UI 不是叠加层，而是灭虫者装备的一部分。主界面是 PDA 的开机画面，战斗 HUD 是防毒面具镜片上的投影，商店是补给站的终端机，图鉴是手绘记录本。每个界面都有物理载体。

地铁面具 + STALKER PDA

② 信息清晰 CLARITY

战斗中一切决策所需信息一目了然——参考 Into the Breach 的 8×8 网格信息排布原则。状态栏贴边放置不遮挡核心视野（Dead Cells 模式），数值简洁到极致，每个数字都有语义图标。

ITB 网格 + Dead Cells 状态栏

③ 受控衰减 PATINA

界面带有物理质感——锈蚀边框、铆钉点缀、磨损划痕、胶带修补——但"受控"意味着磨损是系统性的装饰层，不影响可读性。磨损程度暗示设备等级：越新的界面越干净，越旧的越斑驳。

Fallout 受控腐蚀 + TLOU 胶带
核心概念：灭虫者的随身装备包。想象玩家角色是一个穿梭在废墟中的职业灭虫者——手腕上戴着改造过的 PDA（辐射 Pip-Boy 概念），脸上戴着防毒面具（地铁概念），背包里塞着手绘的蟑螂图鉴（最后生还者概念），腰带上的终端机连接着补给站网络（看门狗 ctOS 概念）。所有 UI 都从这套世界观中生长出来。

视觉特效 VISUAL EFFECTS

全局叠层 GLOBAL OVERLAY

CRT 扫描线全局半透明叠层（opacity:.03），在特定事件触发时增强：Boss 出场闪烁、成就解锁乱码、过热报警红屏。参考 Signalis 的故障条纹作为非全局常驻效果。

触发场景：Boss出场 → 扫描线剧烈抖动 0.5s
触发场景：成就解锁 → 乱码 → 正常文字 0.3s
触发场景：武器过热 → 全屏红色脉冲 0.2s
触发场景：加载界面 → Glitch色差 → 正常

动效原则 MOTION RULES

所有过渡动画≤0.3s（即时反馈），避免过度装饰。Hover 仅改变颜色/边框，不做位移。页面切换使用淡入淡出，不做滑动翻转。

页面切换：opacity 0→1, 0.25s ease
卡片 Hover：border-color + box-shadow, 0.3s
按钮 Active：scale(0.96) + color change, 0.15s
成就解锁：乱码 → 正常文字, 0.3s
Boss 闪入：scanline shake + red flash, 0.5s
