赛博朋克 2077CD Projekt RED · 夜之城的霓虹终端操作系统

CD Projekt RED 打造的开放世界 RPG 巨作。玩家扮演雇佣兵 V，在赛博朋克都市「夜之城」中追逐不朽的传奇。其 UI 设计是一套企业操作系统视觉语言——纯黑底、荧光黄主导、洋红警示、青色系统状态，配合 L 形 HUD 方括号框架与扫描线噪点，将夜之城的霓虹广告、军事终端与数据面板融为一体。这不是「深色模式」，而是刻意保留高密度、强对比、故障感的夜之城界面系统。

SEC.01

游戏概述 GAME OVERVIEW

《赛博朋克 2077》的 UI 不是传统游戏的「简洁深色模式」，而是 CD Projekt RED 为夜之城世界观量身打造的企业操作系统视觉语言。它融合了军事终端的高密度信息、企业数据屏的冷感以及夜之城霓虹广告的视觉冲击，构成了一个完整、自洽的界面系统。

01

纯黑底色

背景以纯黑/近黑为基调，模拟「屏幕在数据激活前的关闭状态」。所有面板、卡片、HUD 都浮于深空之上，强调数据即光。

02

荧光黄主导

荧光黄/近黄绿色是 V 的标识色——HUD 文字、主要操作、弹药数字、伤害反馈、任务路径全部统一为黄色系，在暗底上形成最强可读性。

03

三色功能码

洋红=危险/入侵/警报，青色=系统/骇入/网络状态，蓝色=经验/RAM 容量。颜色即信息，玩家扫一眼即知状态。

SEC.02

设计哲学 DESIGN PHILOSOPHY

赛博朋克 2077 的 UI 哲学可归纳为「信息密度优先」——尽量减少空白，将生命、弹药、任务、地图、状态等信息尽量贴近玩家视线，形成高密度、高紧迫感的终端式界面。

L 形方括号框架 HUD BRACKETS

方括号容器——HUD 元素以 L 形方括号包裹，模拟瞄准镜、卫星层和数据面板，是赛博朋克 2077 最核心的视觉签名
信息锚定——方括号将信息「锚定」在屏幕四角，减少中央干扰，同时暗示「画面被系统标记」
等宽终端排版——全大写、宽字距、等宽数据排版，使界面更像企业终端或军事显示面板

世界观即界面 DIEGETIC UI

夜之城即 UI——菜单和暂停界面使用半透明面板，让玩家仍可看到背景中的夜之城场景，形成「世界即 UI」效果
义体即身体——Ripperdoc 界面将义体改装呈现为身体终端，安装义体时 V 坐入手术椅，通过动画增强沉浸感
超梦即调查——超梦界面分为视觉层（橙）、热成像层（蓝）、音频层（绿），用颜色层叠加实现「多感官回放」
SEC.03

界面分析 INTERFACE ANALYSIS

以下逐项分析 10 个核心界面元素的视觉风格、布局特征与设计逻辑。

① 加载界面 LOADING SCREEN

动画化纹理——加载屏幕并非静态背景，而是通过纹理动画、视频文件与引擎内局部动画循环播放，要求轻量、优化、循环自然
品牌化开场——游戏 logo 以霓虹 LED、色彩闪烁和动态进场呈现，与夜之城的霓虹广告视觉一致
暗色基调——延续纯黑/近黑背景，强调屏幕被数据激活前的等待感
终端氛围——HUD 方括号、扫描线、故障位移、霓虹发光等元素强化加载界面的「终端运行中」错觉
① 加载界面 · 纯黑底 + 荧光黄 LED + 故障位移（风格示意图）

② 主菜单 / 暂停菜单 MAIN MENU

半透明面板——主菜单使用半透明 UI 面板，让玩家仍可看到背景中的夜之城场景，形成「世界即 UI」效果
按钮风格——低饱和、窄矩形条状按钮，悬停时强化发光或边框反馈，材质接近半透明玻璃/数据终端面板
品牌标识——标题 logo 以 LED 霓虹风格呈现，颜色由荧光黄、霓虹粉、青色构成
菜单布局——暂停菜单条目纵向排列，以荧光黄、青色、洋红作为高亮/选中/警告反馈
字体——主字体 Rajdhani（HUD/任务/统计），次要字体 Orbitron（标签/装饰/小尺寸信息），全大写宽字距
② 主菜单 · 半透明面板 + 夜之城背景可见（风格示意图）

③ 战斗界面 / HUD COMBAT HUD

信息密度优先——尽量减少空白，将生命、弹药、任务、地图、状态等信息贴近玩家视线
小地图——右上角圆形局部地图，主任务路径黄色虚线、自定义标记蓝色虚线，危险区域红色提示框
任务信息——屏幕右侧中部，Rajdhani 字体显示任务名称与目标，状态通过颜色变化反馈
武器/弹药——右下角显示当前武器与弹药，弹药以红色数字（弹匣）/蓝色数字（备弹）区分
状态效果——角色信息区附近显示正面/负面状态图标，中毒/失血/义体过载/药效/增益/负面
伤害数字——高饱和荧光黄色浮动数字，确保复杂场景中清晰可见，是 HUD 信息密度的一部分
③ 战斗 HUD · L 形方括号 + 高信息密度（风格示意图）

④ 任务日志 / 关卡选择 JOURNAL / QUEST LOG

层级结构——通过主菜单 → 角色界面 → 任务日志等层级组织信息，任务分为主线/支线/世界事件
经验与等级——左上角显示角色等级与蓝色经验条，升级/获得经验时通过高亮与进度条变化提示
任务状态——标题、状态说明与进度条区分当前目标/已完成/可接受/失败，形成信息密集型终端界面
任务路径——小地图上黄色虚线引导主任务路径，蓝色虚线引导自定义标记

⑤ 商店 / Ripperdoc SHOP / RIPPERDOC

商品展示——物品以网格或列表形式呈现，可浏览商品详情、属性与价格
货币——Eurodollars（eddies），玩家资金/商品价格/购买后余额变化构成主要交互反馈
Ripperdoc 界面——义体改装核心入口，按身体系统分类（头部/循环/免疫/神经/皮肤/骨骼/四肢）
义体容量——左侧黄色条显示当前义体使用上限，右侧蓝色条显示护甲值（2.0 后义体与护甲绑定）
沉浸感——安装义体时 V 坐入手术椅，通过不同植入类型动画增强场景沉浸感

⑥ 天赋 / 技能树 PERK TREE

属性与技能——技能树按属性组织，技能分为 4 级（需 4/9/15/20 点对应属性），2.0 更新后重新组织
层级结构——Tier 1 基础（4 点）→ Tier 2 中级（9 点）→ Tier 3 高级（15 点）→ Tier 4 顶级（20 点），部分末端分裂为两分支
视觉组织——分支、层级与连接线组织，可购买/已购买/锁定/奖励型技能通过颜色与边框区分
UI 层级——纯黑背景、荧光黄标题、青色系统信息、洋红警告，符合夜之城数据终端美学
⑤⑥ Ripperdoc + 技能树 · 身体终端 + 层级分支（风格示意图）

⑦ 成就系统 ACHIEVEMENTS

平台列表——Steam/PS/Xbox 平台列表显示成就总数、获得率与玩家进度
图标与描述——每个成就对应一个风格化图标与达成条件说明，隐藏成就达成前隐藏描述
稀有度——显示稀有度（如 Very Rare）与达成率
视觉风格——延续终端式信息展示，图标/数字/状态/稀有度作为核心反馈

⑧ 数据库 / 碎片 / 图鉴 CODEX / SHARDS

碎片 Shards——游戏内阅读内容（文章/传单/笔记/世界信息/技术资料），按 Articles/Leaflets/Notes/World/Technology 分类
数据库 Codex——查看角色/世界/事件/背景资料，通过分类→条目列表→详情页组织，终端式排版
车辆目录——车辆以卡片/缩略图/列表形式呈现，显示名称/状态/归属/任务关联
视觉风格——深色背景、Rajdhani/Orbitron 字体、细线边框、少量高亮，强化数据档案感
⑧ 数据库 / 图鉴 · 终端式数据档案（风格示意图）

⑨ 战斗生命条 HEALTH BAR

位置——左上角，与经验条、状态图标、Cyberdeck RAM 容量并列显示
生命值——横向条状，通过长度与颜色变化反映当前生命状态
RAM 容量——蓝色竖线/竖条显示义体骇入系统 RAM 容量，与生命条相邻
护甲值——2.0 后义体界面右侧蓝色条显示护甲值，义体与护甲系统紧密结合
战斗反馈——受到伤害时生命条与状态图标共同提供即时反馈

⑩ 视觉特效 VISUAL EFFECTS

超梦 Braindance BRAIN DANCE

视觉层——橙色，观察视觉线索
热成像层——蓝色，发现热源/冷源
音频层——绿色，分析声音线索
编辑模式——层切换/时间轴/片段选择/剪辑工具

扫描模式 Scanning SCAN MODE

金色——任务相关物品
红色——危险威胁
绿色——可骇入装置
蓝色——可互动物体

故障效果 Glitch FX LAYERS

故障位移——面板或图像元素短暂错位成水平切片后恢复
色散分离——青色/洋红/黄色边缘分离，形成 RGB 故障感
扫描线——低透明度水平条纹模拟 CRT 老化屏幕
CRT 噪点——背景与面板表面叠加轻微纹理，增强终端感
使用原则——故障效果作为信号不稳定提示，不宜过度使用
⑩ 超梦 + 扫描模式 · 三色分层 + 四色编码（风格示意图）
